# Support

## Questions and setup help

Use a GitHub issue and select the feature request form when proposing an improvement. For defects, use the bug report form and include sanitized logs, the deployment method and clear reproduction steps.

Before opening an issue, check the README, deployment guide and existing issues. This is a community project, so response times are not guaranteed.

## Security and private data

Do not post Plex tokens, private media paths, viewing history or sensitive screenshots in an issue. Report security problems privately using the process in `SECURITY.md`.

## Plex support

This project is an independent companion application and is not affiliated with, maintained by or supported by Plex. Issues with Plex Media Server itself should be directed to Plex support.
